# Company Compass

Private workspace for researching target companies and tracking professional outreach.

## Local development

1. Copy `.env.example` to `.env.local` and fill in the Supabase URL and publishable key.
2. Run `npm install` then `npm run dev`.
3. Open the app, sign up with email and password, confirm via the email link, then log in.

This app is not deployed yet. GitHub and Vercel come after local testing.
